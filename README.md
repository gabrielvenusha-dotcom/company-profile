## Deskripsi
Website company profile untuk perusahaan fiktif "Nusa Studio" (studio digital). Dibuat dengan React (Vite), Tailwind CSS, dan React Router. Terdiri dari 5 halaman: Beranda, Tentang Kami, Layanan, Portofolio, dan Kontak (form dengan validasi sederhana). Tampilan responsif untuk desktop dan mobile.

## Teknologi
- React + Vite
- Tailwind CSS v4
- React Router
- Data konten disimpan di `src/data/*.json` dan ditampilkan dengan `map()`

## Cara Menjalankan
```bash
npm install
npm run dev
```
